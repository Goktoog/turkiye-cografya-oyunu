# 🇹🇷 Türkiye Coğrafya - KPSS İl Bilme Oyunu (v1.0)

KPSS Coğrafya sınavına hazırlanırken kendim için geliştirdiğim il bilme oyunu gün geçtikçe farklı özellikler de ekleyeceğim tarım dağlar göller vb. Kısacası harita üzerinden Türkiye illerini bulmaya dayalı interaktif web uygulaması.

## 🚀 Özellikler (v1.0)
- SVG tabanlı interaktif Türkiye haritası.
- 81 il arasından rastgele şehir sorma algoritması.
- Doğru ve yanlış sayıları ile anlık başarı yüzdesi takibi.
- Mobil ve masaüstü uyumlu (Responsive) tasarım.

## 🛠️ Teknolojiler
- HTML5
- CSS3 (Flexbox/Grid & Custom Properties)
- JavaScript (ES6+ Native Vanilla JS)
